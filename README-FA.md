# LectureFlow 🎙

🌐 مستندات:

* 🇺🇸 [English](https://github.com/kiaashkan/LectureFlow/blob/main/README.md)
* 🇮🇷 [فارسی](https://github.com/kiaashkan/LectureFlow/blob/main/README-FA.md)

پلتفرم تبدیل گفتار به متن و تحلیل هوشمند محتوای آموزشی با استفاده از هوش مصنوعی

فایل صوتی کلاس، سخنرانی یا هر محتوای صوتی دیگر را آپلود کنید تا به‌صورت خودکار موارد زیر تولید شوند:

* متن کامل (Transcript)
* استخراج اصطلاحات تخصصی
* استخراج فرمول‌ها
* خلاصه‌سازی هوشمند توسط هوش مصنوعی

این پروژه برای دانشجویان، پژوهشگران، مدرسین و هر فردی که به تحلیل محتوای صوتی نیاز دارد طراحی شده است. LectureFlow برای ضبط‌های واقعی کلاس ساخته شده: فایل‌های طولانی (یک ساعت و بیشتر) که از انتهای کلاس و با کیفیت پایین ضبط شده‌اند.

## امکانات

* 🎙 **تبدیل گفتار به متن** — تبدیل فایل‌های صوتی به متن با استفاده از Groq Whisper، با امکان انتخاب مدل توسط کاربر:
  * 🎯 **Whisper Large v3** — دقیق‌ترین حالت، کندتر
  * ⚡ **Whisper Large v3 Turbo** — سریع‌تر، با دقت اندکی کمتر

* 🗣 **پیاده‌سازی انگلیسی** — تبدیل ویس به متن به زبان انگلیسی انجام می‌شود؛ رابط کاربری سایت به ۱۱ زبان در دسترس است

* ⏱ **پشتیبانی از فایل‌های طولانی** — فایل‌ها به‌صورت خودکار در مرورگر تکه‌تکه می‌شوند تا سخنرانی‌های یک‌ساعته هم بدون مشکل پردازش شوند

* 🧪 **استخراج و اعتبارسنجی فرمول‌ها** — شناسایی و بررسی فرمول‌های بیان‌شده در فایل صوتی

* 💊 **استخراج اصطلاحات تخصصی** — شناسایی واژگان و مفاهیم مهم

* 📋 **خلاصه‌سازی هوشمند** — تولید خلاصه‌ای کوتاه و کاربردی از محتوای جلسه

* 🧠 **تحلیل با اولویت دقت** — مدل MiniMax M3.1 Flash از طریق NVIDIA NIM، همراه با جایگزین‌های خودکار در صورت خطا (بخش معماری را ببینید)

* 🌙 **پشتیبانی از حالت تاریک و روشن**

* 📱 **سازگار با موبایل**

* ☁️ **استقرار کاملاً Serverless روی Cloudflare Workers**

## راه‌اندازی

### ۱. دریافت کلیدهای API

#### Groq (تبدیل گفتار به متن)

1. وارد https://console.groq.com شوید.
2. حساب کاربری ایجاد کنید.
3. بخش API Keys را باز کنید.
4. یک کلید جدید بسازید.
5. کلید خود را کپی کنید (`gsk_...`).

#### NVIDIA NIM (تحلیل محتوا — MiniMax M3.1 Flash / GLM-5.3 Flash)

1. وارد https://build.nvidia.com شوید.
2. حساب کاربری ایجاد کنید.
3. بخش API Keys را باز کنید.
4. یک کلید جدید ایجاد کنید.
5. کلید خود را کپی کنید (`nvapi-...`).

---

### ۲. استقرار روی Cloudflare Workers

1. وارد https://workers.cloudflare.com شوید.
2. یک Worker جدید ایجاد کنید.
3. کد پیش‌فرض را با فایل `worker.js` جایگزین کنید.
4. پروژه را Deploy کنید.

---

### ۳. تنظیم متغیرهای محرمانه

در پنل Worker وارد بخش زیر شوید:

Settings → Variables and Secrets

سپس متغیرهای زیر را ایجاد کنید:

| نام            | مقدار     |
| -------------- | --------- |
| GROQ_API_KEY   | gsk_...   |
| NVIDIA_API_KEY | nvapi-... |

بایندینگ‌های اختیاری (برای جایگزین تحلیل و شمارنده بازدید):

| بایندینگ   | نوع               | نام        |
| ---------- | ----------------- | ---------- |
| AI         | Workers AI        | —          |
| DB         | دیتابیس D1        | lecture-db |
| ANALYTICS  | Analytics Engine  | page_views |

پس از ذخیره، Worker را مجدداً Deploy کنید.

---

### ۴. استفاده از LectureFlow

آدرس Worker خود را باز کنید:

```text
https://your-worker.workers.dev
```

فایل صوتی را آپلود کنید و منتظر بمانید تا تحلیل به‌صورت خودکار انجام شود.
