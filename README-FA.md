# LectureFlow 🎙

🌐 مستندات:

* 🇺🇸 [English](https://github.com/kiaashkan/LectureFlow/blob/main/README.md)
* 🇮🇷 [فارسی](https://github.com/kiaashkan/LectureFlow/blob/main/README-FA.md)

تبدیل گفتار به متن برای درس و سخنرانی، با قدرت هوش مصنوعی

فایل صوتی کلاس یا سخنرانی را آپلود کنید و **متن کامل** آن را تحویل بگیرید — نه چیزی بیشتر، نه چیزی کمتر. LectureFlow فقط یک کار انجام می‌دهد و همان را خوب انجام می‌دهد: تبدیل صدای درس به متن دقیق.

این پروژه برای دانشجویان، پژوهشگران، مدرسین و هر فردی که متن یک سخنرانی را لازم دارد طراحی شده است. LectureFlow برای ضبط‌های واقعی کلاس ساخته شده: فایل‌های طولانی (یک ساعت و بیشتر) که از انتهای کلاس و با کیفیت پایین ضبط شده‌اند.

## امکانات

* 🎙 **تبدیل گفتار به متن** — تبدیل فایل‌های صوتی به متن با استفاده از Groq Whisper، با امکان انتخاب مدل توسط کاربر:
  * 🎯 **Whisper Large v3** — دقیق‌ترین حالت، کندتر
  * ⚡ **Whisper Large v3 Turbo** — سریع‌تر، با دقت اندکی کمتر

* 🗣 **پیاده‌سازی انگلیسی** — تبدیل ویس به متن به زبان انگلیسی انجام می‌شود؛ رابط کاربری سایت به ۱۱ زبان در دسترس است

* ⏱ **پشتیبانی از فایل‌های طولانی** — فایل‌ها به‌صورت خودکار در مرورگر تکه‌تکه می‌شوند تا سخنرانی‌های یک‌ساعته هم بدون مشکل پردازش شوند

* 📋 **کپی و دانلود** — متن را کپی کنید یا آن را به‌صورت فایل `.txt` یا PDF دانلود کنید

* 🌙 **پشتیبانی از حالت تاریک و روشن**

* 📱 **سازگار با موبایل**

* ☁️ **استقرار کاملاً Serverless روی Cloudflare Workers**

## راه‌اندازی

### ۱. دریافت کلید API

#### Groq (تبدیل گفتار به متن)

1. به https://console.groq.com بروید
2. یک حساب بسازید
3. بخش API Keys را باز کنید
4. یک کلید جدید بسازید
5. کلید را کپی کنید (`gsk_...`)

---

### ۲. استقرار روی Cloudflare Workers

1. به https://workers.cloudflare.com بروید
2. یک Worker بسازید
3. کد پیش‌فرض را با `worker.js` جایگزین کنید
4. منتشر کنید

---

### ۳. تنظیم Secretها

داشبورد Worker را باز کنید و به مسیر زیر بروید:

Settings → Variables and Secrets

Secret زیر را بسازید:

| نام          | مقدار    |
| ------------ | -------- |
| GROQ_API_KEY | gsk_...  |

Bindingهای اختیاری (برای شمارنده بازدید):

| Binding   | نوع              | نام        |
| --------- | ---------------- | ---------- |
| DB        | دیتابیس D1       | lecture-db |
| ANALYTICS | Analytics Engine | page_views |

بعد از ذخیره، دوباره منتشر کنید.

---

### ۴. شروع استفاده

آدرس Worker خودتان را باز کنید:

```text
https://your-worker.workers.dev
```

یک فایل صوتی آپلود کنید تا LectureFlow به‌صورت خودکار آن را به متن تبدیل کند.
